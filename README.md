# 🏥 Healthcare Management MySQL Project

A relational database project developed using **MySQL** to manage and analyze healthcare data including patients, doctors, appointments, treatments, diagnoses, departments, and billing information.

The project demonstrates practical SQL skills such as database design, table relationships, joins, aggregate functions, subqueries, views, and window functions.

---

## 📌 Project Overview

The Healthcare Management Database is designed to organize healthcare-related information in a structured relational database.

The database helps analyze:

- 👥 Patient information
- 👨‍⚕️ Doctor information
- 📅 Appointments
- 🏥 Departments
- 🩺 Diagnoses
- 💊 Treatments
- 💰 Billing and payments
- 📊 Healthcare-related trends and statistics

---

## 🎯 Project Objectives

- Design a structured healthcare relational database.
- Store and manage patient and doctor information.
- Track appointments, diagnoses, treatments, and billing.
- Establish relationships between different healthcare entities.
- Perform SQL-based data analysis.
- Practice advanced SQL concepts.
- Generate meaningful insights from healthcare data.

---

## 🗂️ Database Tables

The project contains the following major tables:

| Table | Description |
|---|---|
| `Patients` | Stores patient demographic and personal information |
| `Doctors` | Stores doctor information and specialization |
| `Departments` | Stores hospital department information |
| `Appointments` | Stores patient-doctor appointment records |
| `Diagnosis` | Stores patient diagnosis information |
| `treatments` | Stores treatment-related information |
| `Billing` | Stores billing, payment, and revenue information |
