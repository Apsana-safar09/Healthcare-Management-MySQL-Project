# Healthcare Management MySQL Project

## 📌 Project Overview

This project is a relational healthcare management database developed using MySQL. It is designed to manage and analyze healthcare-related information including patients, doctors, departments, appointments, diagnoses, treatments, and billing.

The project demonstrates practical SQL and database management concepts through structured tables, relationships, analytical queries, and an Entity Relationship (ER) diagram.

## 🎯 Objectives

- Design a structured healthcare relational database
- Store and manage patient and hospital-related information
- Establish relationships between healthcare entities
- Perform data analysis using SQL queries
- Generate meaningful healthcare and revenue insights

## 🗄️ Database Tables

The database contains the following major tables:

- Patients
- Doctors
- Departments
- Appointments
- Diagnosis
- Billing
- Treatments

## 💻 SQL Concepts Used

The project covers:

- Basic SQL Queries
- SELECT, INSERT, UPDATE and DELETE
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN
- LEFT JOIN
- Subqueries
- Correlated Subqueries
- Filtering and Sorting
- Data Analysis Queries

## 📊 Healthcare Analysis

The database was used to analyze:

- Patient distribution
- Doctor information
- Appointments
- Disease and diagnosis patterns
- Treatment costs
- Consultation fees
- Payment status
- Monthly revenue
- Healthcare billing information
